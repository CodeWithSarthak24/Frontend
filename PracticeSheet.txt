5. What is the difference between display:none and visibility:hidden?

Ans: 

display:none : By default property it does nothing element.

display:block : It change the element from inline to block. These element starting from next line and occupy full space horizontally and space does not depend upon content dimension.

display:inline : It change the element from block to inline. These element starting from same line and occupy space bases on content. But if we apply height, width, padding and margin
to element then, horizontal dimension will get shrink.

display:inline-block : It element behave like inline but horizontal dimension will not shrink.

display:flex : It is apply on parent container to make containera flex container and it direct child become flex items.

display:grid : It is apply on parent container to make containera grid container and it direct child become grid items.

visibility:hidden: It make an html element hidden but the space will remain there.

2. A <nav class="bar"> contains a logo <span> and three links. Use Flexbox so the logo is on the left, the
links are on the right, everything is vertically centered, and there is a 12px gap between the links.
Height: 60px.

Code:

<body>

<nav class="bar" style="display:flex; 
justify-content: center; align-items: center; gap: 12px; height: 60px ">
<a href="#">Home</a>
<a href="#">About</a>
<a href="#">Login</a>
</nav>

</body>


3. 3. Grid page layout (10 pts)
Using CSS Grid, build a page with a header across the top, a 200px sidebar on the left, a main area that
fills the rest, and a footer across the bottom. Use grid-template-areas. The page must be at least 100vh
tall.

Code:

<body>

<div class="container">
    <header class="header">Header Area</header>
    <aside class="sidebar">Sidebar Area</aside>
    <main class="main-content">Main Content Area</main>
    <footer class="footer">Footer Area</footer>
  </div>

</body>

 <style>

    .container {
      display: grid;
    
      grid-template-columns: 200px 1fr; 
      grid-template-rows: 1fr ; 
      min-height: 100vh;
      box-sizing: border-box;

      grid-template-areas:
          "header  header"
          "sidebar main"
          "footer  footer";
    }

    .header {
      grid-area: header;
      padding: 10px;
